# A research that is there

A research is added to, asked and checked, and never rewritten. Where the first word the person typed is the name of a research the map holds, the run is on that research. Every kind of run below keeps what `references/folder.md` rules: a fact's words and a saved source never change, a number is never used again, and what is new is a dated round at the end of the log.

## Which kind of run it is

What follows the name says which kind of run it is. Take the first of these that fits:

1. **Nothing follows the name.** Give where the research stands, from the lines the command printed, and say in plain words what can be asked of it. Where its last run was cut off, as Where it stands tells it, say that too, and that the name with `carry on` after it takes that run up. That is the whole reply: nothing is gathered, and nothing is written.
2. **Taking up a run that was cut off**, where the person asks for the run to be carried on, taken up or finished.
3. **Handing it over**, where the person asks for the research to be handed over, copied out or given to someone.
4. **Does this agree**, where the person names a spec, a design, a diff, a branch or a pull request to hold against it.
5. **What a build learned**, where the person names a work item that was built and asks for what its build found.
6. **Does it still hold**, where the person asks whether the research, or a fact of it, still holds or is still right, or asks for the whole of it to be checked again. An ask to look again at a subject, and not at the research or one of its facts, is a question, below.
7. **A question**, for anything else. A part of it that the facts answer is answered from them, as a plain question is. A part they do not answer is a new question for the research, and a round is run for it.

A run that was cut off is never left under a newer round. A kind that writes a round takes it up first, as A run that was cut off has it, and then does what was asked: the fourth, the fifth and the sixth kind each write a round, and so does a question with a part the facts do not answer. A kind that writes none, a hand-over or a plain question, leaves the run as it is, and its reply says that the last run was cut off and that the name with `carry on` after it takes it up.

The fourth, the fifth and the sixth kind are told in `references/checks.md`, a file of this skill beside this one. Where the run is one of them, read that file now, whole, in this turn: a later turn may be refused it.

Then say the one line on the way in, for every kind and before another command is run: that the run is on this research, which kind it is, and, where the day to check again by has passed, that it has. The kind is the one that what was typed asks for: whether a cut-off run comes first, and whether the facts answer the whole of a question, are learnt later and are no part of the line. Where the name also reads as the first word of what was asked, as `limits on the gateway are how high` does for a research named `limits`, the run is on that research all the same, and the line says as well that a new research is asked for with another word first.

## Where it stands

`context-central research open <name>` printed where the research stands, a line each. Three of its lines steer the run:

- `item:` names the work item the research belongs to, where it has one. That item's state file is read and written as step 4 of the skill has it.
- `rounds:` tells whether the last run was cut off. It ends `not stopped` where that run stopped before it wrote the round that stops it. It reads `rounds: none` where no round is written yet, and then the brief tells, for every kind but a hand-over, which does not ask: run `context-central resolve <name> --absolute`, run `context-central draft` on the brief it lists, and read the brief at the path that prints. With a question under its `## Questions`, a run was cut off before its first round. With none, no run has begun and nothing was cut off. A bare name runs `context-central take` once the brief is read, which clears a draft that was only read.
- `check again by:` ends `passed 1 day ago` or `passed <N> days ago` where the day on the sheet has gone by. Say so twice, whatever kind the run is: in the one line that says the way in, and in the first line of the reply the run ends on, after what that line answers or tells. Where this run wrote the day anew, that line gives both: the day that had passed, and the day the research is to be checked again by now. Where it reads `no date on the sheet`, no day was written yet, as where the first run was cut off: nothing has passed, and nothing is said of it. The day is written anew, in place of the one that was there, by the last round of a run that gathers, which a round on more questions, a run taken up that has a lead to read and what a build learned each are, and by the check of whether it still holds, where it compared a fact. The check of whether something agrees leaves the day, as it leaves the whole sheet, and a kind that writes no round writes no day.

A kind finds the files of the research so, where its own part says which of them it reads or writes: run `context-central resolve <name> --absolute`, which lists the fact sheet, its pages, the brief, the log, the reading and the set-aside list, and run `context-central draft` on each file before it is read or written. Use the path `draft` prints, never the one `resolve` printed. Every `context-central take` puts the drafts into the map and removes them, and every round is opened with one: after a `take`, run `context-central draft` again on each file before it is read or written. Where the research has an item, a kind that takes the numbered steps runs `context-central resolve <item> --absolute` as well: it gives the places of the item's spec and design, which the choice of the next step reads.

A bare name, a hand-over and a plain question take none of the skill's numbered steps: each says here all that it does, the commands it runs among them. Every other kind reads the sheet, its pages and the brief before anything else, found as above, and takes the steps so:

- Nothing of step 1: it makes no folder and adopts no item.
- Of step 2, what the kind says it gathers, and no more. The skills of the estate's own for research, a repo's and the estate's as `references/agents.md` has them under Skills of the estate's own, are run for a round on more questions and for a run taken up before its first round, and for no other kind. A connection's skill is its sweep in any round that sweeps it.
- Step 3 as it is, but that the points of a run that gathers name the facts it wrote or superseded: a fact it left as it was is named by a point of the run that wrote it, and not again. A check's points are the ones its own part gives. Where the run names a work item that is not the research's own, as a check of that item's spec does, the next step is chosen for that item and said in the last line alone: no file of that item is written.
- Of step 4, the files the kind's own part has its round write. Every round writes its entry in the log, and the run its part of the reading, laid out and placed as step 4 of `SKILL.md` has it, with the template it asks for. A round that gathers writes the fact sheet too, as step 4 has it, and so does the check of whether it still holds. The check of whether something agrees leaves the sheet as it is. The link to the fact sheet is written only where it is not there yet, as it may not be where an earlier run was cut off. Its `take`, `lint` and `graph` are run as step 4 has them.
- Step 5 as it is.

## More questions: a round on it

A part of what was asked that the facts answer is answered by fact number before the brief is given, at the head of the message that gives it. For the rest a round is run:

1. **The brief.** Turn that part into questions about what is so, as `references/run.md` has it, and add them under `## Questions` in the brief with the next numbers: the questions of a research are never numbered again from `Q1`. Add a line under `## Sources to cover` for each place this run will look that is not there yet, and strike none but one the person says to leave out. Under `## Depth` and under `## Start line`, add this run's lines below the earlier ones, after a line that holds the run's day alone, as `2026-11-29:`. The earlier lines stay, so that the brief goes on saying where each run looked. This run's start line is written from `context-central connections --json` and the session's tools, as `references/run.md` has it, with no line on git, which the first run wrote. Where it would hold no line, it is one line: that no connection is recorded and no tool of the session reaches one. Then agree the brief as a new research's is agreed: it is the one thing the run waits on, and with nobody there it waits on nothing.
2. **The rounds** go as `references/run.md` has them. Each is opened with `context-central take` and `context-central research open <name>`, so that a round's number, its first fact and its first saved source go on from the ones the folder holds, and after that `take` each file is drafted again before it is read or written. The first round of this run sweeps as the first round of any run does, and it writes this run's questions under `## Questions` on the sheet with its facts, so that no entry of the log names a question the sheet lacks. An agent, and a connection's own skill, is handed the questions this run added, and no question of an earlier run. The cap of the depth counts the rounds of this run, not the rounds the research has had.
3. **A fact that gains a source** keeps its words and its number: add a `- Source:` line under it, and the source to the sheet's list.
4. **A fact that no longer holds** is superseded in the round that found it so. Before a round is written, hold what it read against the facts that stand: one that a source read in this round shows to be otherwise no longer holds, whatever the round was asked. Write the fact that takes its place, with the next number and under it `- Supersedes F<n>, <YYYY-MM-DD>: <the reason>`. Move the older fact from the sheet, or from the page that held it, to that round's entry in the log, under `### Superseded`, word for word with every line under it. A source that only the older fact names stays in the sheet's list of sources. A fact whose `From` line names a fact that was superseded is judged too: where what it says no longer follows, it is superseded, and where it still follows, it stays as it is. Where the older fact answered a question, the round's `Answered` line names that question by the fact that took its place.
5. **The sheet and the reading.** The last round of the run writes the day to check again by, in place of the one that was there. The run adds its own part to the reading, which names the facts this run wrote or superseded and no fact that it left as it was. A fact that no longer held is a point under Needs a fix there: what was planned or built on the older fact rests on something that is no longer so. Nothing else that an earlier run wrote is changed.

## A run that was cut off

A run was cut off where the `rounds:` line ends `not stopped`, or reads `none` while the brief holds a question, as Where it stands tells the two. It is taken up where the person asks for that, and before a kind that writes a round does what it was asked. Where the person asks for it and no run was cut off, say so, with what stopped the last run as the `rounds:` line gives it, or that no run has begun where that line reads `none`, and what can be asked of the research: that is the whole reply, with nothing more read and nothing written.

- **Cut off among its rounds**, where `rounds:` ends `not stopped`. The brief stands as it was agreed and is not shown again. The run goes on at the depth the last lines under the brief's `## Depth` give, and its cap counts the rounds from here. The open leads are the ones in the `New leads` lines of the last round's entry, with each line under `## Bring in` on the set-aside list that no fact, saved source or entry of the log names, and the next round is opened as every round is. Each is read as step 2 of the skill reads its kind. A lead's line names no connection: `fetch` finds the one a ticket or a pull request belongs to, and anything else is read as a page on the web unless the brief's start line names a connection that plainly holds it. One that cannot be read so is a gap. Where that entry's `New leads` line says `none` and nothing waits under `## Bring in`, no lead is open and nothing is gathered: the next round's entry is written all the same, with the questions still open on its `Open` line, `none` on its other lines, and `no lead is open, so another round would add no fact and no lead` as its `Stopped` line, so that the log says the run has stopped. That round writes nothing on the sheet, so the day to check again by stays as it is. No entry that is in the log already is changed to say it.
- **Cut off before its first round**, where `rounds:` reads `none` and the brief holds a question. Nothing says whether that brief was agreed. So it is given again as it stands and agreed as a new research's is, and with nobody there it is taken as written. Where it lacks its depth or its start line, write that first, as `references/run.md` has it, and write neither a second time: a depth the brief holds stands, whoever is there now. Then the run goes from its first round, as `references/run.md` has it.

The rounds of the run taken up are the ones after the last entry of the log that has a `Stopped` line, or every round where no entry has one, with the rounds written from here. When it stops, the run writes one part of the reading for all of them: it names the facts of every round of the run, the ones written before the cut among them. Where the person typed more than an ask to take the run up, that is handled once the run has stopped, as its own kind has it, with a part of the reading of its own where that kind writes one. The link of step 4, its `take`, `lint` and `graph`, and the closing answer come once, after both, and the answer holds the points of both.

## A plain question about it

A question the facts answer is answered from the research's folder and from nothing else:

- Run `context-central resolve <name> --absolute`, then `context-central draft` on the sheet and its pages, and on the log where the person names a number the sheet does not hold, and read each at the path `draft` prints.
- Answer in a few lines, with no groups, and name the facts each line rests on by number, as `(F7, F8)`.
- A number the person names that the sheet no longer holds was superseded. Say so, with the fact that took its place, the day and the reason from that fact's `Supersedes` line, and the older words as the log keeps them.
- Gather nothing: no agent, no fetch, no sweep, and no read outside the research's folder. Write nothing: no round and no part of the reading. Run `context-central take` at the end, which clears the drafts that were only read.
- Where the last run was cut off, a line after the answer says so, and that the name with `carry on` after it takes it up.
- The last line is `Research: <the place of the fact sheet in the map>.` It names no step, since nothing new was found.

## Handing it over

`context-central research handover <name> <folder>` copies the research into a folder that stands by itself, to attach to a feature or to give to another planner. The folder lies outside the map, and is not there yet or is empty. The copy holds the sheet, its pages, the brief, the log, the set-aside list and the saved sources, with each file of the item's own `sources/` that the research links copied in.

- Where the person named no folder, pick none: say that a folder is needed, and stop, before anything more is run. That is the whole reply.
- A hand-over reads one file of the research, the fact sheet, for the kinds of its sources. Run `context-central resolve <name> --absolute`, run `context-central draft` on the sheet it lists, and read the lines under `## Sources` at the path that prints: the word after the colon on each is that source's kind. Then run `context-central take`, since the command reads the map, and then the command.
- The reading is one person's judgement and is left out, unless the person asks for it: then the command is `context-central research handover <name> <folder> --reading`.
- The person may name kinds of source to leave out, such as mail or chat, which hold other people's messages: add `--without <kind>` for each, as `context-central research handover <name> <folder> --without mail --without chat`. A kind is passed as the person named it, whether or not the sheet's list of sources holds it, and none is left out that the person did not name.
- The command writes nothing unless the whole copy can be made. Where its answer opens `handed over research`, give that line and each line under it: one that opens `left out:` for each kind, and one that ends `only on sources left out` for the facts that name a source left out and nothing that stays in the copy.
- Any other answer is a refusal: the command exits 1 and prints one line on the error stream, which opens `context-central research:` and then says why. Say that nothing was handed over, give the line as it was printed and what would mend it, and mend nothing unasked:
  - One that goes on `no source of` was asked to leave out a kind that no source in the copy has, and lists the kinds there are. The mend is the person's to choose: one of those kinds, or the copy with that kind not named, where the research has no source of it. Do not run the command again until they say which.
  - One that goes on `nothing was handed over` names a file whose link leads outside the research, a file the copy cannot hold, or two files that would take one name. The mend is in the file it names, and is the person's to make.
  - One that names the folder says that it is inside the map, is there already, cannot be reached or could not be written. The mend is another folder.
- A hand-over writes nothing in the map: no round and no reading. Its reply is one line that says what was handed over and where, or that nothing was, then what the command printed. Where a copy was made, it then names each kind left in the copy whose sources are what people wrote or said to one another, as mail, chat, a thread and a meeting are: the kinds are the estate's own words, so judge each by its word. Then, where `rounds:` ends `not stopped`, it says that the last run was cut off and that the name with `carry on` after it takes it up. Its last line is `Research: <the place of the fact sheet in the map>.`

The place of the fact sheet in the map is `research/<name>/index.md`, with the estate's own folder for researches in place of `research` where the path `resolve` printed shows another.
